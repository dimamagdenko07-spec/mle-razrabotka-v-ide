DataFrameReporter выполняет задачу описания данных ДатаФреймов, благодаря ему можно получить следующую информацию:

    1. Размерность ДатаФрейма

    2. Дубликаты в данных

    3. Описательная статистика ДатаФрейма

    4. Пропуски в данных

Чтобы установить окружение с библиотеками для проекта нужно прописать в терминале следующие команды:

    1. py -m venv venv

    2. .\venv/Scripts/activate

    3. pip install requirements.txt

Для запуска проекта используется команда: py main.py
